# Windows Server 2025 Active Directory Home Lab

## Project Overview

This project documents the deployment and administration of a Windows Server 2025 Active Directory environment using Microsoft Hyper-V.

The goal is to develop practical IT support and Windows system administration skills through hands-on configuration, troubleshooting, and documented help-desk scenarios.

## Technologies Used

- Windows Server 2025
- Windows 11 Pro
- Microsoft Hyper-V
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy Management
- NTFS and SMB Share Permissions
- PowerShell and Windows Command Prompt

## Lab Environment

| System | Role |
|---|---|
| DC01 | Windows Server 2025 domain controller and DNS server |
| CLIENT01 | Windows 11 Pro domain-joined workstation |
| homelab.local | Active Directory domain |

## Skills Demonstrated

- Installed and configured Active Directory Domain Services.
- Created organizational units, domain users, and security groups.
- Implemented AGDLP group nesting for role-based file access.
- Configured and verified Group Policy settings.
- Created and secured an SMB network share using Share and NTFS permissions.
- Troubleshot file access issues and verified successful remediation.

## Troubleshooting Documentation

This repository will include hands-on help-desk tickets documenting the reported issue, investigation, root cause, resolution, and verification.
